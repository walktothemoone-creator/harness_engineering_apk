# SALES 제품별 합계 스크립트 — 요구사항 정의서 (REQ-20261116-001)

## 1. 배경 (목적·목표)

- 목적: 매주 손으로 하던 제품별 합계와 검산을 스크립트로 바꿔 시간을 줄이고 실수를 없앤다
- 목표: CSV 하나를 주면 제품별 합계 표(마크다운)가 나오고, 금액이 빈 행은 건너뛴 수를 알려 준다
- 배포 대상: 없음 — scripts에서 끝남
- 이전 작업과의 연결: HIST-20261116-000 "남은 일" 1번

## 2. 요청 원문

> 이번 주 파일부터는 스크립트로 돌려 줘. 금액 빈 줄은 빼고 몇 줄 뺐는지만 알려 줘

| ID | 요구사항 | 수용 기준 |
