# PLAYBOOK — 이 일을 하는 방법, 그리고 나아지는 방법

`docs/`는 무슨 일이 있었는지를 기록한다. 이 파일은 여기서 일하는 **지금까지 알아낸 가장 좋은 방법**을 기록한다. 에이전트는 작업 전에 읽고(SKILL 1단계) 작업 후에 고친다(SKILL 9단계). 체인 밖이라 자유롭게 고치되, 고칠 때마다 근거가 된 작업 기록(HIST ID)을 적어 이유를 늘 따라갈 수 있게 한다.

## 1. 반복 작업 — 지금의 방법

| 작업 | 지금의 방법 (쉬운 말로, 순서대로) | 도구 | 수준 | 언제부터 |
|---|---|---|---|---|

수준 — 끝난 작업의 근거가 있을 때만 한 단계씩 올린다.

| 수준 | 뜻 |
|---|---|
| 1 기록됨 | 매번 손으로 하지만 기록은 남는다 |
| 2 반복 가능 | 방법이 여기에 적혀 있고, 다음 실행이 그대로 따랐다 |
| 3 도구화 | `scripts/_shared/`의 공용 스크립트가 주요 부분을 한다 |
| 4 검사됨 | 자동 검사(시험, 검증)가 결과를 지킨다 |
| 5 스스로 실행 | 에이전트가 혼자 돌리고 보고한다 (루프 단계) |

## 2. 품질 기준 — 여기서 "잘 끝났다"의 뜻

작업을 끝났다고 보고하기 전에 하는 확인. 실수가 빠져나갔으면 확인을 추가한다. 말없이 빼지 않는다.

| 확인 | 이유 (근거가 된 작업 기록) |
|---|---|
