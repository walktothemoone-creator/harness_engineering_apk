H.E.

Harness Engineering

When work with an AI agent starts to repeat, a chat prompt is not enough. A harness keeps the work: what was wanted, how it was planned, what was done, how the code changed and what remains — linked by hashes so the record stays trustworthy.

The seed (repository)

Clone it into a project folder, let your agent run build_skill.md, and your conversation grows into a harness: a docs/ backbone, a work procedure and a hash-chain tool.

  • GitHub repository

Harness Task (Android app)

The same idea in an app: turn a request into a sealed, hash-linked task, and continue with any agent from a compressed summary instead of the whole chat.
